# XAPI - AI API Gateway 项目概览

## 🎯 项目目标

XAPI 是一个 AI API 中转站，为开发者提供统一的、标准的 API 接口，内部聚合多个 AI 平台资源，实现智能路由、故障转移和监控管理。

## 🏗️ 架构设计

### 系统架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    客户端应用                                │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       ▼

│                   XAPI 网关服务                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │

└─────────────────────────────────────────────────────────────┘
```

### 数据流

1. **请求流程**：
   ```
   客户端 → XAPI 网关 → 智能路由 → 适配器 → 外部 API → 响应
   ```

2. **健康检查流程**：
   ```
   定时任务 → Key 检测 → 状态更新 → 告警通知
   ```

3. **代理管理流程**：
   ```
   定时拉取 → IP 检测 → 可用池维护 → 请求路由
   ```

## 🔧 技术栈详情

### 后端技术栈

- **运行时**: Node.js 18+
- **语言**: TypeScript
- **框架**: Express.js
- **ORM**: Prisma
- **缓存**: Redis
- **日志**: Winston + JSON 格式
- **监控**: Prometheus client

### 前端技术栈

- **框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **组件**: shadcn/ui (Radix UI)
- **状态管理**: React Query
- **图表**: Recharts
- **表单验证**: Zod

### 基础设施

- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **容器**: Docker + Docker Compose
- **监控**: Prometheus + Grafana
- **反向代理**: Nginx (可选)

## 📊 监控指标

### 业务指标

- **请求总数**: `xapi_requests_total`
- **成功请求数**: `xapi_requests_success_total`
- **失败请求数**: `xapi_requests_failed_total`
- **平均延迟**: `xapi_request_latency_seconds`
- **各模型使用量**: `xapi_model_requests_total`

### 系统指标

- **Key 健康状态**: `xapi_key_health_status`
- **可用代理 IP 数**: `xapi_proxy_available_count`
- **数据库连接数**: `xapi_db_connections`
- **Redis 缓存命中率**: `xapi_redis_hit_rate`

## 🚀 部署方案

### 开发环境

```bash
# 1. 克隆项目
git clone <repository>
cd xapi

# 2. 配置环境
cp .env.example .env
# 编辑 .env 文件

# 3. 启动服务
docker-compose up -d

# 4. 访问应用
# 前端: http://localhost:3000
# 后端: http://localhost:3001
```

### 生产环境

1. **基础设施准备**
   - 云服务器 (2核4G以上)
   - PostgreSQL 数据库
   - Redis 缓存
   - 域名和 SSL 证书

2. **部署步骤**
   ```bash
   # 1. 拉取代码
   git clone <repository>
   
   # 2. 配置环境变量
   cp .env.production .env
   
   # 3. 构建和启动
   docker-compose -f docker-compose.prod.yml up -d
   
   # 4. 配置反向代理
   # Nginx 配置 SSL 和负载均衡
   ```

3. **监控配置**
   - 配置 Prometheus 抓取目标
   - 导入 Grafana 仪表盘
   - 设置告警规则

## 🔒 安全考虑

### API 安全

- **Key 加密存储**: 数据库中 API Key 加密
- **请求签名**: 支持 HMAC 签名验证
- **速率限制**: 防止滥用
- **IP 白名单**: 可选的 IP 访问控制

### 数据安全

- **敏感信息脱敏**: 日志中隐藏 API Key
- **数据备份**: 定期数据库备份
- **访问控制**: 基于角色的权限管理

### 运行安全

- **容器隔离**: 各服务独立容器
- **资源限制**: CPU/内存限制
- **健康检查**: 自动重启失败服务
